    Each state can run more than one recipe. Whichever you pick is recorded with every session, so switching engines never muddies the log.

    Volume guide: set it so the sound sits behind your thoughts, present but ignorable. If it competes with a normal speaking voice at arm's length it is too loud for hours-long use; lab-effective noise levels sit near hearing-safety limits, so favor the lowest level that still works for you. Pure tones concentrate all their energy at one frequency, so keep those quieter than the noise beds and take breaks on very long sessions.
